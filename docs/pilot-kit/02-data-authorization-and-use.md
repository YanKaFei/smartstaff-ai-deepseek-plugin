## 2. 数据范围

仅限与人力预测相关的经营数据：

- 匿名门店编号、营业日期、桌型、入座人数；
- 排队、叫号、入座、结账、离店、清台时间；
- 实际在岗人数、岗位、服务模式；
- 服务员工作分钟观察（岗位/动作/起止时间/分钟）；
- 店长的“缺人/合适/偏多”判断及原因。

**不采集**：顾客姓名、手机号、支付账号、订单金额明细、身份证、员工个人联系方式、聊天内容。

## 3. 用途

- 仅用于本门店影子预测、工作量分析、预测误差评估和报告；
- 不用于招聘筛选、绩效处罚、工资结算、营销或向第三方出售；
- 不用于真实派单；本阶段 Shadow Mode 不发出邀约/班次。

## 4. 去标识化与存储

- 门店使用匿名编号；员工使用匿名工号（如 S01）；
- 原始文件由试点团队在受控目录保存，访问限于试点负责人/工程/管理员；
- 报告只展示聚合指标，不展示可识别个人或顾客的信息；
- 授权撤回后停止新增采集，按约定删除或匿名化保留。
