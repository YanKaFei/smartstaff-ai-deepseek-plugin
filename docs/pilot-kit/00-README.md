# R5.1 首店试点现场工作包

本目录是门店现场可直接打印/填写的材料；模板与系统导入字段一致。

| 文件 | 用途 | 负责人 |
| --- | --- | --- |
| `01-store-info-registration.md` | 门店信息登记（一页） | 试点负责人 |
| `02-data-authorization-and-use.md` | 数据授权及用途草案（待法律审核） | 门店负责人/法务 |
| `03-daily-export-guide.md` | 每日数据导出/观察流程 | 观察员/试点团队 |
| `04-server-work-minute-observation.md` | 服务员工作分钟观察表 | 观察员 |
| `05-manager-daily-feedback.md` | 店长每日反馈表 | 店长（内部代录） |
| `06-14-day-calendar.md` | 14 天执行日历 | 试点负责人 |
| `07-2-3-hour-trial.md` | 2–3 小时首店试采方案 | 试点负责人/观察员 |
| `R5-PILOT-EVENTS-TEMPLATE.csv/.xlsx` | 经营事件导入模板 | 观察员 |
| `R5-WORKLOAD-TEMPLATE.csv/.xlsx` | 工作量导入模板 | 观察员 |

## 核心分工

- **店长**：每天只填一页反馈；**不逐桌重复录入事件**。
- **观察员**：负责无法自动导出的叫号/入座/离店/清台与工作分钟观察。
- **内部测试人员**：导入、质量检查、代录反馈、生成日报。
- **工程**：回放/指标/报告；不发送真实邀约。

## 安全边界

当前保持 Shadow Mode：不发送真实兼职邀约、不创建真实班次、不产生用工费用。未经授权数据不得导入。
