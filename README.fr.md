# SmartStaff AI

**SaaS de gestion de personnel pour restaurants, avec une couche d’analyse DeepSeek.**

SmartStaff AI est un **framework de test** multi-tenant : comptes organisation, magasins, managers et extras, marketplace inter-magasins, moteur de capacité déterministe, analyse DeepSeek et console d’administration.

[EN](README.md) · [ZH](README.zh-CN.md) · [KO](README.ko.md) · [JA](README.ja.md) · **FR**

## Modules

- comptes SaaS, rôles, invitations ;
- console d’organisation et onboarding ;
- marketplace d’extras et approbation manager ;
- prévision déterministe + explication DeepSeek ;
- configuration API DeepSeek au premier lancement ;
- opérations shadow-safe.

## Ce que ce n’est pas

Un produit commercial fini. C’est un cadre de test à installer, inspecter et étendre.
